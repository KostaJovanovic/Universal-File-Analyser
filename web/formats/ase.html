What is a .ASE file?

The .ase extension names two unrelated things: an Aseprite pixel-art sprite and an Adobe Swatch Exchange colour palette.

Aseprite sprite

What it is
An Aseprite (or LibreSprite) pixel-art sprite - layered, animated artwork saved by the pixel editor. Analyser composites each frame from its layer stack and plays the animation at the per-frame timings the file carries, alongside the layer tree and the animation tags.
How to tell it apart
An Aseprite sprite carries the magic number 0xA5E0 in its fifth and sixth bytes.

Adobe Swatch Exchange palette

What it is
An Adobe Swatch Exchange palette - the colour swatches shared between Photoshop, Illustrator and InDesign. Analyser identifies it and reads its version and group structure.
How to tell it apart
A swatch file begins with the ASCII signature ASEF.
Did you know
  • Analyser handles .ASE alongside related formats such as .Aseprite.
  • In Analyser's format library, .ASE sits in the System & disk category.
  • Analyser opens .ASE files right in your browser - they are parsed and rendered on your device, never uploaded to a server.
Open a .ASE file
Drag a .ASE file onto the Analyser home page (or tap to pick one). It opens entirely in your browser - nothing is uploaded, there is no account, and it works offline once installed.

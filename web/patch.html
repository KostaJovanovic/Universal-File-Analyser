6.54

Good Question

22 July 2026

  • Every explanation on the site has been rewritten in plain English - and the little [?] buttons that carry them now work the same way everywhere, popping up a tidy note instead of pushing the page around. Alongside: a new on-device tool that strips background noise out of a recording, a friendlier set of one-tap sound filters, and a clear answer when a file has nothing inside to open.

Clearer help

  • NewAnswers in plain English, everywhere. The hundreds of little [?] explanations across the site - on photos, sound, video, documents, 3D models, circuit boards and more - have been rewritten so anyone can follow them, with the jargon translated rather than assumed. Many more readouts, table headings and section titles that never had a [?] now carry one, so there is a plain answer wherever you wonder what something means.
  • NewTidier help that stays put. Tapping a [?] now opens a small pop-up anchored to the button instead of pushing everything below it down the page, and clicking anywhere else closes it. Every [?] across the site behaves the same way.
  • FixA clear answer for an empty file. Dropping a 0-byte file - a broken or unfinished download, or an empty placeholder left behind by a recovery tool - now explains plainly that there is nothing inside to open and suggests looking for another copy, instead of failing with a puzzling error.

Sound

  • NewRemove background noise from a recording. A new denoise option sits beside the vocal tools on any audio file: an on-device AI model (DeepFilterNet3) strips out hiss and background noise while keeping the full sound, and shows the result as a Clean to Noise blend you can play, analyse or save. Like the vocal separation it runs entirely on your device - nothing is uploaded - and downloads its model once, then works offline; you can also add it to the offline download so it is ready with no connection at all.
  • NewFriendlier one-tap sound filters. The instant isolate presets are now Underwater, Radio and Hollow - quick character effects that colour the whole track - while the cleaner, true AI vocal split sits under a clearly labelled AI separation button, with its Standard and Lite models and the new denoise gathered in one row.
  • FixSwitching AI tool mid-prompt now works. Choosing a different model - or the new denoise - while a download prompt was already open used to be silently ignored; it now updates the prompt straight away.

Video

  • FixMotion timelines play for any video. The synced motion and gyro timelines - drawn from a clip’s GoPro, CAMM or Sony sensor track - now play back even when the video uses a codec the browser cannot open directly, by driving them from the same playable copy used for the main player.

6.53

Under The Hood

21 July 2026

  • A deep forensic pass across photos, video and sound - Analyser now reads the hidden internals of each. For photos: tamper tells and concealed data. For video: the container’s structure, the camera’s own telemetry, and the exact encoder that made it. For sound: broadcast-grade loudness, the musical key, and whether a “lossless” file was secretly made from an MP3. And when a video has to be converted just to play, every result now describes the original file, never the converted copy.

Photos

  • NewSpot a doctored photo. A new Advanced section brings proper image forensics to any JPEG: error-level analysis highlights areas saved at a different quality (a classic sign of a paste-in), a quantization fingerprint recovers the true save quality and whether it matches the software the file claims, and JPEG ghosts reveal regions compressed a second time. Together they help you judge whether a picture has been edited.
  • NewFind data hidden inside an image. Bit-plane and least-significant-bit analysis inspects the parts of a picture the eye cannot see, estimates the likelihood that a message or file is concealed there, and lets you browse every bit plane channel by channel.
  • NewRead a photo’s edit history and hidden identity. Analyser now lays out the edit-history trail some files record, checks Photoshop’s own edit marker, and gathers the identifying details a photo carries - GPS location, camera serial, owner name - into a plain privacy report. Derived optics (field of view, depth of field, exposure value) round out the metadata.
  • NewAnalyse a RAW photo two ways. A camera RAW file holds both a ready-made preview and the untouched sensor data. A new switch at the top of the results lets you analyse either - the embedded preview, or the fully demosaiced image built from the raw sensor readings - so you can inspect both sides of the same shot instead of only one.
  • NewDetect codes, and pull every thumbnail. Barcodes and QR codes in a picture are now read automatically, and all the preview images buried inside a file can be extracted at once.

Video

  • NewSee exactly how a video file is built. A new Advanced card opens up an MP4 or MOV’s internal structure - the full tree of its building blocks, every track it holds (video, audio, timecode and hidden data streams), and the tell-tale signs that separate a straight-from-camera file from one that has been re-saved or edited. A frame-by-frame bitrate and keyframe map is read without playing a single frame, and the true frame rate is measured properly, constant or variable.
  • NewRead a camera’s flight recorder. Action-camera and phone footage often carries a hidden telemetry track. Analyser now decodes GoPro and CAMM data - drawing the GPS route on a local map, plotting the accelerometer and gyroscope traces, and reading exposure, temperature and every recorded sensor stream - alongside any single location stamp a video stores.
  • NewFingerprint the encoder and check the stream. Analyser reads deep into the compressed video to recover its true profile, colour and range, cross-checks that against what the container claims - a strong tell for a re-encoded or edited file - and recovers the exact x264/x265 encoder and settings left as a fingerprint in the stream. It also reads full HDR mastering data and Dolby Vision, and flags a C2PA Content Credentials record.
  • NewA whole video at a glance. A content timeline squeezes every part of the video into a single colour “barcode” - a fingerprint of how it looks over time - with a brightness curve beneath it and automatic flags for black frames and frozen or still stretches. Click anywhere on the barcode to jump the player there.
  • FasterPlay unsupported video sooner. When a clip uses a codec the browser cannot play (much GoPro HEVC, for one) and has to be converted, Analyser now makes a fast, lightweight copy by default - 720p and quick - with an Advanced panel to set resolution, frame rate and speed, including an extra-quick Turbo mode.
  • FixAnalysis always describes the original. That playable copy is now used only for playback - every result, from resolution and frame rate to the metadata, telemetry and stream fingerprint, is read from the original file you dropped, never the converted stand-in.

Sound

  • NewA broadcast-grade loudness meter. Beyond the single loudness figure, a full EBU R128 readout now shows integrated, momentary and short-term loudness, the loudness range between quiet and loud passages, and the real true peak between samples that ordinary meters miss - with a loudness-over-time graph against the usual streaming target.
  • NewCatch a fake “lossless” file. Analyser inspects the full frequency picture of a file that claims to be lossless (FLAC, WAV, ALAC) and flags the tell-tale ceiling left behind when it was really made from an MP3 or AAC, naming the likely original quality. It also reports the file’s effective bit depth, exposing padded or upscaled “hi-res” files.
  • NewHear the key, and the hidden tones. The musical key is now estimated to sit alongside the tempo, and a set of forensic listeners flag mains hum (revealing 50 vs 60 Hz mains, a basis for recording-authenticity checks), scan for inaudible ultrasonic tones and watermarks, and decode touch-tone (DTMF) phone digits from a recording.
  • NewSignal-health checks. New crest factor (how heavily a master is compressed) and DC offset (a capture-fault tell) readings join the file info.

Elsewhere

  • FixA clearer 3D mesh verdict. The Mesh integrity card now shows a plain Watertight or Faults found badge in its heading, with friendlier wording for what a “non-manifold” edge actually means.

Disk Dive

20 July 2026

  • Open a raw disk image - a copy of an SD card, USB stick or floppy - like a folder, browse every file inside, and rescue deleted photos the disk no longer lists, right down to a damaged photo’s readable part or its own built-in thumbnail. Everything stays on your device.

6.36 · The disk browser

  • NewOpen a disk image like a folder. Drop a raw disk image (.img, .ima or .dsk) - a copy of an SD card, USB stick or floppy, or a whole-disk clone - and Analyser mounts its FAT12/16/32 filesystem and lays out every file in a browsable tree and treemap. Click any file to analyse it just as if it sat on your own drive, and read the volume label, cluster size and free space alongside. Virtual-machine and optical images (VHD/VHDX, VMDK, QCOW2, VDI, ISO) are identified with their partition table.
  • NewRescue deleted photos from a disk image. Analyser scans the raw sectors of a disk image and carves out every picture it can find - including deleted and orphaned photos the file list no longer points to - then shows them in a gallery you step through with the arrow keys and save. A common way to bring back photos from a formatted or corrupted memory card.
  • NewRebuild a JPEG with no header at all. Photo recovery already fixed truncated and damaged pictures; now it can bring back a JPEG whose header is completely gone, with only the raw image data left. Pick a healthy photo from the same camera and Analyser borrows its header so the file decodes again.
  • NewAndroid app bundles. XAPK, APKM and APKS installer bundles - from APKPure, APKMirror and Google’s bundletool - now open as browsable archives, reading the app name, package, version and permissions from the manifest and listing the base and split APKs and OBB data inside.
  • FixThe 3D-model sample shows in colour. The bundled OBJ sample now carries its colours with it, so it previews with its red lettering instead of plain grey.

6.37 · Deeper photo recovery

  • NewSee the readable part of a damaged photo. A recovered photo whose data is cut short, torn, or partly overwritten no longer comes back blank. Analyser decodes the picture itself now and shows whatever part is still intact - usually the top of the image - with the unreadable rest left grey. This brings back pictures the browser refuses to open at all.
  • NewRecover a lost photo from its thumbnail. When a photo’s full-size image has been overwritten but the small preview stored inside its header survived, Analyser falls back to that thumbnail - so even a picture that is otherwise gone still shows a real, recognisable image of the scene.
  • NewScan when you choose, and see everything found. The raw-sector scan for lost photos waits for a Scan for images button instead of starting on its own, so opening a big disk image stays instant. It then shows every picture it carves - faint fragments and all - as clean thumbnails with Analyse and Download appearing on hover, and a Copy photo list button copies each photo’s location, size and whether it came back with a preview. Each photo shows its capture date read from the picture’s own header (it survives even for deleted files), and you can sort the gallery newest, oldest or largest first.
  • FixRecovered photos no longer flash up blank or garbled. Pictures briefly mis-read as empty during a busy scan now show, and a photo scattered in pieces across the card is reassembled into the real image instead of a jumble.

Watertight

16 July 2026

  • Every 3D model you drop now gets a mesh health-check - Analyser spots the flaws that stop a model printing cleanly or break it in CAD, from surfaces that are not fully sealed to edges where the geometry folds in on itself.
  • NewCheck a 3D model for flaws. Beneath the shape stats for any 3D file - STL, OBJ, 3MF, STEP, glTF, FBX and the rest - a new Mesh integrity card tells you whether the model is watertight (a single fully sealed solid) and free of tangled “non-manifold” edges where three or more faces meet, then counts the open holes, zero-size faces, duplicate faces and back-to-front surfaces it finds. When something is wrong it explains what that means for printing or machining and points you at a repair - so a broken model is caught before it reaches your slicer or printer. It reads the true surface even from files that store every triangle separately, where simpler tools wrongly flag the whole model as broken.
  • Maintenance - small interim tidy-ups, including a project readme update.

6.21 - 6.31

Provenance

14 July 2026

  • An image-provenance and forensics pass - read a photo’s Content Credentials, weigh whether it was AI-generated, strip its identifying metadata, and lay out every date a file carries on a single timeline - alongside a new browsable documentation site.
  • NewSee a photo’s Content Credentials. When an image carries a C2PA “Content Credentials” record, Analyser now unpacks what it claims - the tool that signed it, the edits made to it, any source images it was built from, whether an AI tool had a hand in it, and the signing certificate’s details. It reads the record rather than cryptographically checking it, so this is provenance the file asserts, not proof of authenticity - and the card says so plainly.
  • NewWeigh up whether a picture is AI-generated. A new card gathers the tell-tale signs that an image came from - or was touched by - a generative-AI tool: generator names left in the metadata, the standard “digital source type” AI marker, and the hidden generation-parameter blocks that tools like Stable Diffusion, ComfyUI and Midjourney leave behind. It shows the evidence and lets you judge rather than passing a verdict - a missing signal proves nothing, since metadata is easily stripped or forged.
  • NewStrip a photo’s hidden metadata. One click removes the identifying metadata - EXIF, XMP, IPTC, comments and the GPS location inside them - from a JPEG, PNG or WebP and hands back a clean copy. It works by container surgery, not re-encoding, so the picture and its colours come out bit-for-bit identical; only the tell-tale data is gone.
  • NewA file’s dates, on one timeline. A new card collects every timestamp a file carries - the “last modified” your device reports, the created and modified dates written inside Office documents, a video’s internal recording time, an image’s saved time - lines them up in order, and flags anything that cannot be true, like a file changed before it was created or stamped in the future. It stays hidden unless a file actually has two or more dates worth comparing.
  • NewA proper documentation site. There is now a browsable documentation site - a readable, searchable guide to what every part of Analyser does and how the pieces fit together, for anyone curious about how it all works. Its feature pages show the real controls inline as live, interactive examples - the actual buttons, cards and colour swatches from the app, responding to your taps and switching just as they do on the site, in both light and dark. The site footer was reorganised into clearer sections at the same time.
  • Maintenance - the open-source readme and developer notes were refreshed. The public code readme was rewritten with screenshots of the app in action, and internal documentation added alongside it. The internal UI style-guide sheet was restored and brought back in step with the current buttons, footer and offline panel too. Nothing on the site itself changes; this is purely for anyone reading or building on the source.

  • NewA live data grid. Click a column header to sort by it, filter any column (a range for numbers, a text match for everything else), search across every column at once, and show, hide or reorder columns. Click a cell to read its full value, or drag to select a rectangle, a whole row or a whole column.

  • NewRecognises more date formats. A column written in a statistics agency’s quarter/month notation (2011.06) or a day/month/year date with dots, dashes or slashes (31.12.2024, 8/25/2024) is now read as a real date - sortable and chartable - instead of being mistaken for a plain number or dismissed as text. Dates default to day first, matching the site’s conventions, but a column that can only be American - a value like 8/25/2024, where 25 can never be a month - is detected automatically and read month first, with a Dates: D/M/Y toggle beside the grid to switch either way by hand.

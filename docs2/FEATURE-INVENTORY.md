# Feature inventory (coverage checklist)

The working contract the `features/*` docs must satisfy: every user-triggerable
control, grouped by the feature doc that owns it. Built from the `ROUTES` table in
`web/assets/js/core/app.js` (every renderer represented) and a grep of the 40
button-creating renderers (`anr-btn`). A ticked box means the control is documented
in its feature doc. Blunt and complete by design - it is a checklist, not polish.

Verification notes:
- `ROUTES` renderers: every `kind` -> renderer mapping below is represented.
- `anr-btn` hits: the 40 renderers that create buttons (verified via grep) are all
  accounted for under a feature doc.
- `web/test.html` is build output (generated by `prerender-testpage.mjs`) and was
  not present in the working tree; documented from the generator + `CLAUDE.md`.
